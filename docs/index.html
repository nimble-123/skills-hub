Every folder your AI tools read, on one map.

skills-hub is a desktop library for the skills, agents, commands and rules of sixteen AI coding tools. It works on the folders those tools actually read — disabling moves the file, linking makes a symlink — so what you are looking at is the ground itself, not a copy of it.

01

Sixteen conventions, and nothing that showed them all at once

Every tool invents its own convention for where these things live — some global, some per project, most both. The same prompt ends up pasted into three folders and drifting apart, and a checkbox in a manager that never touches the file the tool reads has not disabled anything.

So: one library over the real folders, and every action a real one.

02

Ground truth: switching something off moves it

Disabling an item moves the file into a .skillmanager-disabled folder beside where it was, and enabling moves it back. The tool genuinely stops seeing it — there is no flag for it to ignore.

Field notes~/.claude/skills/

    It is symlink-aware. A relative link moved one folder deeper gains one ../ rather than being flattened into an absolute path, so a shared skills folder keeps working after the round trip — which is why this map measures its scale in levels of ../.

    03

    Your tags live in your vault

    One small markdown file per item, with frontmatter, in a folder you choose. Put it in an Obsidian vault and the tags sync with everything else you keep there, and stay queryable from Dataview.

    • A note is only rewritten when something actually changed.
    • A note carrying your own tags is never removed automatically.
    • Your skills are never moved or copied into it — only the notes live there.
    04

    New ground: install it, and read the diff first

    Search the skills.sh registry by name, or point it at any repository git can reach — no account and no token either way. A search result names a repository; watching one clones it, walks it and lists everything installable in it.

    Anything installed records the commit it came from, so it can be checked for updates, shown as a diff before anything is overwritten, and put back exactly the way it was.

    05

    Elevation is cost

    Read the land in section. What rises above the datum is what a tool carries on every turn — an item's name and description, so the model knows it exists. What lies beneath is what loads only once the item is invoked. skills-hub keeps the two apart, because only the first is a standing cost.

    Where a tool keeps a session history — Claude Code and Codex do — that history says which items have actually been used, instead of guessing from how old a file is. It is read on request, not on every scan.

    06

    Everything else it reads, read-only

    Every MCP server every tool is configured with, global and per project, listed and left alone. Plugin bundles from Claude Code and Codex, with their items in the library and the bundle switchable as a whole.

    07

    From the menu bar, on macOS

    A status item with a popover: search the whole library, switch an item on or off, and go back to what you were doing. The panel takes the keyboard without activating the application, so typing in it does not pull you out of your editor.

    Closing the window leaves it running. The popover and the window switch the same files and each tells the other what changed, so neither goes stale.

    Eighteen editions of the same sheet

    The nine palettes VS Code ships with, five you would otherwise install, both SAP Fiori Horizon themes, and the two it started with. A palette is a set of colours and nothing else — it never changes a size, a spacing or a typeface.

      InterfaceSystem · Inter · Geist · Figtree · IBM Plex Sans · Roboto

      Nine typefaces ship with the application, Latin cuts only, so a choice looks the same on every machine and needs no network.

      10

      Strata: built to be checked

      Three layers, dependencies pointing inwards only. The domain crate never imports Tauri — enforced by cargo deny, not by discipline — and $HOME is injected rather than read, which is what makes the scanner testable against temporary directories.

      ARCHITECTURE.md has the long version; SPEC.md what the application guarantees on disk, each guarantee cited to the test that holds it up.

      11

      Getting there

      A universal build — Apple silicon and Intel in one.

      brew install --cask nimble-123/tap/skills-hub

      Builds are not signed yet, so macOS objects the first time. Open the app, let it be refused, then allow it under System Settings → Privacy & Security, where an Open Anyway button now sits — or take the quarantine flag off yourself: 

      xattr -dr com.apple.quarantine /Applications/skills-hub.app
      winget install nimble-123.skills-hub

      The winget manifest is in review. Until it is merged, take the -setup.exe from the latest release.

      The .deb or the .AppImage from the latest release — which is also where every other installer comes from.

      Needs Rust, Node and pnpm. Produces a .app and a .dmg, or your platform's equivalent.

      git clone https://github.com/nimble-123/skills-hub
cd skills-hub
pnpm install && pnpm tauri build

      On first launch it asks where to keep its notes. Your skills are never moved or copied — only those notes live there.
