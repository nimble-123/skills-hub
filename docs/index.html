01

WhyEvery tool keeps its own folders. Nothing shows you all of them.

Some folders are global, some belong to a project, most tools use both. The same prompt ends up pasted into three of them and drifts apart.

And a checkbox in a manager that never touches the file the tool reads has not disabled anything. So: one library over the real folders, and every action a real one.

Five of the places it reads

  • ~/.claude/skills
  • ~/.cursor/rules
  • ~/.codex/prompts
  • ~/.config/opencode/agents
  • ~/.agents/skills

02

Real filesOff means moved. The tool genuinely stops seeing it.

Disabling moves the item into a .skillmanager-disabled folder beside where it was, and enabling moves it back.

It is symlink-aware: a relative link is recomputed for its new depth rather than replaced with an absolute path, so a shared skills folder keeps working after the round trip.

pdf Skill Enabled Enable the pdf skill and the linked sap-abap skill
Folder ~/.claude/skills/.skillmanager-disabled/pdf/SKILL.md
Symlink ~/.claude/skills/.skillmanager-disabled/sap-abap → ../../../.agents/skills/sap-abap

Try the switch. One more level deep, one more ../ — the link still resolves.

03

NotesYour tags live in your vault.

One small markdown file per item, with frontmatter, in a folder you choose. Put it in an Obsidian vault and it syncs with everything else you keep, queryable from Dataview.

A note is only rewritten when something in it actually changed. Your own tags, prose and unknown keys survive every rescan, and a note carrying your tags is never removed automatically. Your skills themselves are never moved into it or copied.

notes/pdf-….md---
entryId: pdf-…
name: pdf
type: skill
tool: claude-code
enabled: true
tags:
  - documents
favorite: false
---

Use for forms, not scans.

04

DiscoverFind it, install it, and see the diff first.

Search the skills.sh registry by name, or point it at any repository git can reach. No account, no token.

Watching a repository clones it and lists everything installable in it. Anything installed records the commit it came from — so it can be checked for updates, shown as a diff before anything is overwritten, and put back the way it was.

05

CostWhat it carries every turn, and what it costs once used.

Every enabled item puts its name and description in front of the model each turn, so the model knows it exists. The body loads only when it is invoked. The cost page keeps those two apart.

Where a tool keeps a history, that history says which items were actually used — rather than a guess from how old a file is.

459MBof Claude Code and Codex session history, read to learn what was actually run —

284ms— in this long. Fast enough to be the default, not a report you wait for.

06

Read-onlyEverything else it finds, it shows you.

Every MCP server every tool is configured with, global and per project — listed, not edited.

Plugin bundles from Claude Code and Codex, with their items in the library and each bundle switchable as a whole.

07

macOSA menubar companion.

Search the whole library from the menu bar, switch an item on or off, and go back to what you were doing. The panel takes the keyboard without activating the application, so typing in it does not pull you out of your editor.

Closing the window leaves it running. The popover and the window switch the same files and each tells the other what changed.

08

IndexSixteen tools, and where each one looks.

The global folders each tool reads by default. Most add project folders of their own, which are scanned per workspace.

Every path is editable, so a tool that moves its folders — or a setup that was never standard — does not have to wait for a release.

    11

    InstallFree, MIT, on every desktop.

    A universal build — Apple silicon and Intel in one.

    brew install --cask nimble-123/tap/skills-hub
    winget install nimble-123.skills-hub

    The winget manifest is in review. Until it is merged, take the -setup.exe from the latest release.

    The .deb or the .AppImage from the latest release — which is also where every other installer comes from.

    pnpm install && pnpm tauri build

    Clone the repository first. On macOS the build produces the .app and a .dmg.

    Not signed yet. macOS will refuse it the first time. Open the app, let it be refused, then allow it under System Settings → Privacy & Security, where an Open Anyway button now sits. Or take the quarantine flag off yourself:

    xattr -dr com.apple.quarantine /Applications/skills-hub.app

    On first launch it asks where to keep its notes. Your skills are never moved or copied there — only the notes live in it.
